## 🔥 Особенности дизайна

### Визуальные эффекты:
- **Анимированные частицы** - 100 светящихся частиц, соединяющихся линиями
- **3D-эффект наклона карточек** - карточки реагируют на движение мыши
- **Киберпанк-сетка** - анимированная фоновая сетка
- **Плавающие неоновые фигуры** - 4 больших светящихся объекта
- **Glitch-эффект на заголовке** - случайные искажения текста
- **Неоновое свечение** - все элементы светятся неоновыми цветами
- **След от мыши** - светящиеся частицы следуют за курсором
- **Анимация счётчиков** - цифры в статистике анимируются
- **Волновой эффект на кнопках** - при клике расходятся круги
- **Блики на карточках** - световые блики скользят по карточкам
